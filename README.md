# MOGMAX

MOGMAX is a satirical visual novel about looksmaxxing culture, self-image, and the pressure to reinvent yourself.

## Chapter 1 — Chopped

An insecure high-school student is eating alone when Clav, an intense believer in maxxing, sits across from him and decides that his life needs an intervention.

What begins as an uncomfortable lunch turns into a choice between accepting the person he already is and following Clav into a strange promise of transformation.

## Playing the game

Available in **English** and **Spanish**. Pick your language from the title screen.

### macOS

Download `MOGMAX-2.2-mac.dmg`, double-click it, and drag **MOGMAX** into your
Applications folder. That's it — launch it like any other app.

The app is signed with an Apple Developer ID and notarized by Apple, so macOS
opens it without any security warning. If you *do* see one, you almost
certainly have an older unsigned build — delete it and re-download.

### Windows

Download `MOGMAX-2.2-pc.zip` and **extract it before playing** — don't run the
game from inside the zip preview window. Windows will happily let you
double-click straight into a zip, and the game will fail to save because it
can't write back into the archive.

1. Right-click the zip → **Extract All…** → pick a folder.
2. Open the extracted folder and run **MOGMAX.exe**.

On first launch Windows may show a blue **"Windows protected your PC"**
SmartScreen banner, because the `.exe` isn't code-signed (Windows signing
certificates are a separate, paid thing from Apple's). Click **More info** →
**Run anyway**. This is expected and only happens once.

### Browser

Playable directly at [tarzerk.itch.io/mogmax](https://tarzerk.itch.io/mogmax) —
nothing to install. Best on desktop; audio needs a click to start on some
mobile browsers.

### Saves

Progress, chapter unlocks, and volume settings live outside the game folder, so
they survive updates — you can delete and replace the app without losing saves.
